# 记忆能力评测计划模板

使用说明：按三层次框架构造评测集，每层各 20 个用例。核心约束是**更新记忆时不可回看原始对话**，这样记忆本身成为唯一信息源，才能真实衡量记忆质量而非长上下文能力。

---

## 1. 评测流程

```
会话 1 → 生成记忆
   ↓（仅能访问记忆，不可回看原始对话）
会话 2 → 根据记忆修改记忆
   ↓
…重复直到该用例所有会话处理完毕
   ↓
用记忆回答一个新的用户问题
   ↓
LLM-as-a-judge 与参考答案对比 → 奖励得分
```

## 2. 用例规格

| 层次 | 用例数 | 构成 | 通过标准 |
| --- | --- | --- | --- |
| 第一层 基础回忆 | 20 | 通常由**单个会话**构成，含大量事实细节 | 精确返回直接提供的结构化信息 |
| 第二层 多会话检索 | 20 | 多个**跨时间、跨对象**的会话（合计约 50 轮） | 检索出全部相关信息并正确推理 |
| 第三层 主动服务 | 20 | 多个跨时间跨对象会话（合计约 50 轮） | 无明确指令下主动整合与预警 |

## 7. 评分方法

- 用**另一个 LLM 当评委（LLM-as-a-judge）**，将回答与参考答案对比打分。
- 建议分维度打分后加权：事实准确性 / 完整性 / 主动性 / 无幻觉。
- 每个用例取奖励得分，按层汇总均分。
