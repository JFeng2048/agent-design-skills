# PII 脱敏与隐私策略表

使用说明：本表定义**哪些数据敏感、在哪脱敏、怎么脱敏、存多久**。
默认原则：**检测与脱敏在本地完成，原始敏感值不出本机**；记忆中只存掩码或引用，需要时从受控存储按需取回。

---

## 1. PII 类型清单

| 类别 | 例子 | 检测方式 | 脱敏方式 | 是否进记忆 |
| --- | --- | --- | --- | --- |
| 结构化 | 身份证号 | 正则 + 本地 LLM | 全掩码，仅存后 4 位 | 否（存引用） |
| 结构化 | 银行卡号 | 正则 + 本地 LLM | 全掩码，仅存后 4 位 | 否（存引用） |
| 结构化 | 手机号 | 正则 | 中间 4 位掩码 | 视业务 |
| 结构化 | 邮箱 | 正则 | 域名保留、前缀掩码 | 视业务 |
| 半结构化 | 地址 | 本地 LLM | 保留到区县级，门牌掩码 | 视业务 |
| 自然语言 | 「我的密码是 abc123」 | 本地 LLM | **整句丢弃并告警** | 否 |
| 自然语言 | 健康状况、宗教信仰等敏感属性 | 本地 LLM | 按业务决定是否存储 | 需用户同意 |
| 关系类 | 家人姓名与关系 | 本地 LLM | 可存（业务需要），但需 backstory 标注 | 是（带消歧字段） |

## 2. 脱敏位置

| 位置 | 时机 | 作用 | 是否默认启用 |
| --- | --- | --- | --- |
| 日志落盘前 | 写入前 | 避免敏感信息进入存储与备份 | 是 |
| 提取前 | 喂给 LLM 做记忆提取前 | 避免进入模型上下文与推理过程 | 是 |
| 检索返回时 | 返回调用方时 | 按调用方权限决定返回原始值或掩码值 | 是 |
| 展示时 | 前端/终端渲染 | 防止肩窥与截图泄露 | 视业务 |

## 3. 检测方案

| 方案 | 适用 | 特点 |
| --- | --- | --- |
| 本地小模型（如 Qwen3 0.6B 经 Ollama） | 默认方案 | 可在 CPU / 消费级设备运行；召回率 95%+；假阳性显著低于正则 |
| 更大规格本地模型（1.7b / 4b） | 精度要求更高 | 成本与延迟上升 |
| 正则快速过滤 | 高吞吐场景的第一道 | 快，但覆盖不全（漏自然语言类） |
| 混合策略（正则 + LLM） | 超高吞吐 | 正则过滤明显模式，LLM 深度分析剩余文本 |

**禁止**：把含敏感信息的日志发送到云端 API 做脱敏——发送本身即泄露，违背隐私保护初衷。

识别结果用 **JSON Schema 结构化输出**，包含：敏感信息类型、位置、置信度。

## 4. 存储与保留

| 数据 | 保留期限 | 删除方式 | 备注 |
| --- | --- | --- | --- |
| 用户画像（语义记忆） | {{长期，直至用户注销}} | 硬删除 + 索引清理 | 用户可请求导出 |
| 事件记忆（情景记忆） | {{如 1 年}} | 到期自动归档后删除 | 归档不进检索 |
| 只增日志 | {{如 90 天}} | 滚动删除 | 删除需覆盖备份 |
| 向量索引 | 与源记忆同步 | 源删除后同步删除 | 避免残留可检索 |

## 5. 遗忘权（删除）检查清单

删除请求必须覆盖全部副本：

- [ ] 长期记忆库
- [ ] 只增日志（append-only log）
- [ ] 向量索引
- [ ] 备份与快照
- [ ] 缓存（检索结果缓存、会话缓存）
- [ ] 下游派生数据（聚类摘要、泛化出的语义记忆）

## 6. 权限矩阵

| 角色 | 读原始值 | 读掩码值 | 导出 | 删除 |
| --- | --- | --- | --- | --- |
| 用户本人 | 是 | 是 | 是 | 是 |
| Agent 运行时 | 按需（受控） | 是 | 否 | 否 |
| 客服 | 否 | 是 | 否 | 否 |
| 开发/运维 | 否 | 否 | 否 | 否 |

## 7. 审计

| 项 | 要求 |
| --- | --- |
| 脱敏日志 | 记录脱敏次数、类型分布，不记录原始值 |
| 访问审计 | 记录谁在何时读取了哪类记忆（不记录内容） |
| 异常告警 | 出现「密码」「密钥」类表述时告警 |
| 定期复核 | 每季度复核 PII 类型清单与脱敏召回率 |
