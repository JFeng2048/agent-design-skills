# 检索管线规格

使用说明：本文件是检索管线的**实现契约**——每一路的配置、融合与重排参数都要可复现。参数变更需重跑评测并记录。

---

## 1. 管线总览

```text
查询 → [稠密检索] ┐
        [稀疏检索] ┴→ 融合(RRF) → Top-N 候选 → 跨编码器重排序
        → 多文档配额分配 → 上下文感知注入（带来源标记）
                 ↑
   知识组织层：分块 + 上下文说明 + 结构化索引（可选）+ 链接/索引页
   更新层：PR 化增量更新 + 定期整理 + 失效下线 + 权限过滤
```

## 8. 关键参数速查

| 参数 | 默认值 | 调优方向 |
| --- | --- | --- |
| chunk_size | 256-1024 token | 召回不足 → 调小；噪声大 → 调大…（以 recall@k 判定） |
| chunk_overlap | 10%-20% | 边界截断严重 → 加大 |
| k1 | 1.5 | 词频重复多 → 调小（更快饱和） |
| b | 0.75 | 文档长度差异大 → 调大 |
| RRF k | 60 | 想更信任头部结果 → 调小 |
| rerank Top-N | 50 | 延迟敏感 → 调小；精度优先 → 调大 |
| 配额 α | 1.0 | 想保护低分文档 → 调小；想强化高分文档 → 调大 |
| QUOTA_MAX | 不限 | 仍出现霸屏 → 设上限（但单文档场景会自动拿满 K） |
