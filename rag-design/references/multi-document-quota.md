# 多文档配额分配：候选池 → 最终 Top-K

重排序之后得到候选片段列表，这些片段可能来自多个文档。此时还有一个独立问题：**K 个名额如何在文档之间分配**。

## 1. 直接按分数取 Top-K 的三个问题

| 问题 | 表现 |
| --- | --- |
| **单文档霸屏** | 某文档因多条高分片段占满全部名额，其他相关文档无法进入 |
| **硬性限制的副作用** | 为防霸屏设置「单文档最多 N 条」，在只有该文档相关时导致信息不足 |
| **名额浪费** | 某文档候选片段不足配额时，剩余名额被浪费 |

## 2. 核心流程

```text
① 计算文档代表分数
   rel(d) = max(该文档所有候选片段的分数)

② 归一化为权重（α 控制集中度）
   w_d = rel(d)^α / Σ rel(d)^α

③ 配额分配（最大余额法）
   q_d = floor(K · w_d)
   余位按小数部分降序依次 +1
   钳制：q_d ≥ 1（有候选就至少 1 条）

④ 按配额取片段
   每个文档内按分数取前 q_d 条

⑤ 缺口回填
   候选不足配额时，缺口按顺位分给其他文档
```

## 3. 参数

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| `K` | 总名额数 | 由上下文窗口决定，通常 5-20 |
| `α` | 集中度旋钮 | 默认 1.0，需实验确定 |
| `QUOTA_MIN` | 每文档最低配额 | 默认 1 |
| `QUOTA_MAX` | 每文档最高配额 | 默认不限 |

### α 的行为

| α 值 | 效果 |
| --- | --- |
| α = 1 | 严格按相关性比例分配 |
| α < 1 | 向平均倾斜，低分文档被保护 |
| α → 0 | 完全平均 |
| α > 1 | 向高分文档倾斜 |

## 4. 算法定位

- **学术渊源**：比例代表制思想（PM-2 / Sainte-Laguë），采用更易工程化的**最大余额法**（Hare-Niemeyer）。
- **工程特性**：纯函数、O(N log N)、**零 LLM 调用**、可单测、延迟可忽略。
- **与现有系统的关系**：决定总 K 值的逻辑（`_resolve_dynamic_top_k` 一类）是上游，**配额分配器**（`allocate_quota`）决定 K 如何在文档间分配，两者是上下游关系。

## 5. 解决的问题对照

| 问题 | 解法 |
| --- | --- |
| 单文档霸屏 | 按权重比例分配，高分文档拿得多但不能独占 |
| 硬性条数限制 | 配额动态计算，单文档场景自动拿满 K 条 |
| 低分文档被忽略 | α<1 时向平均倾斜，提供保底名额 |
| 名额浪费 | 缺口回填机制 |
| 总名额不精确 | 最大余额法严格保证总名额等于 K |

## 6. 实现注意

- **分数可能为负**（余弦相似度取 -1~1）：权重计算前需把代表分数平移为正值，否则 `rel^α` 在小数 α 下无定义。
- **钳制后总和可能偏离 K**：先按 `QUOTA_MIN`/`QUOTA_MAX` 钳制，再对未被钳制的文档增减以回到 K。
- **缺口回填顺序**：按「剩余需求 + 小数部分余额」排序，优先给最该拿到的文档。
- **文档内去冗余不在本算法职责内**：同一文档内多个片段高度相似时，需叠加 MMR / xQuAD。

## 7. 边界与后续

**不解决的**：

- 文档内片段冗余（需叠加 MMR / xQuAD）。
- `max` 聚合对「多片段平均相关」文档的偏差（可改为 top-m 均值）。

**后续可叠加**：

- **xQuAD 的新颖度衰减层**：处理文档内去冗余，与配额分配互补——配额解决「文档间怎么分」，xQuAD 解决「文档内选哪几条」。

## 8. 验收

用 `scripts/quota_allocator.py` 验证：

| 检查项 | 期望 |
| --- | --- |
| 总名额 | 严格等于 K（除非所有文档候选总和 < K） |
| 单文档场景 | 该文档自动拿满 K 条 |
| 文档覆盖数 | 相比直接取 Top-K 提升 |
| 单文档最大占比 | 不超过设定上限（若设了 QUOTA_MAX） |
| α 敏感性 | 用 `--alpha-sweep` 观察不同 α 下的分配变化 |

指标建议与召回指标一并观测：

- **文档覆盖率**：命中的不同文档数 / 相关文档总数。
- **单文档最大占比**：最终 Top-K 中单个文档的最高占比。

## 9. 自检

- [ ] 候选池到 Top-K 之间有多文档配额分配，不是直接按分数截断
- [ ] 配额总名额严格等于 K
- [ ] 未用「单文档最多 N 条」的硬限制代替动态配额
- [ ] 有缺口回填，不会浪费名额
- [ ] α 已用实验确定，而非默认了事
- [ ] 分数可能为负时已做平移处理
- [ ] 文档内冗余问题已知悉（如需则叠加 MMR / xQuAD）
